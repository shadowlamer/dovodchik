# STATUS — Креативный доводчик

Обновлено: 2026-11-03.

## Что сделано (сеанс 2026-11-03)

- Приложение переписано из «доводчика с антуражем» в нейтральный инструмент «Креативный доводчик»: нейтральные промпты, в подвале только две строки (вдохновлено идеями Пелевина; данные — только localStorage и указанный endpoint).
- Исправлен зеркальный обход UV у граней ЗАД/ПРАВО/ЛЕВО — из-за него текст на гранях был зеркальным/перевёрнутым; таблицы UP/R теперь выводятся из GEO программно, угол компенсации — `atan2(r_y, w_y)`.
- Чипы: строго четыре, фиксированные позиции по сторонам сцены, состояния «ждёт/ошибка/готов», клик по ошибке перезапускает генерацию.
- Куб поворачивается только с готовым вариантом: ожидание без поворота, поздний ответ отменённого клика игнорируется, при ошибке поворота нет.
- Оси и варианты — один запрос (JSON-массив из четырёх объектов {"ось","вариант"}), лимит токенов ×4; недостающие варианты добираются точечными запросами; мусорный ответ — один строгий ретрай.
- Автопродолжение после фиксации (кнопки «продолжить» нет), автоприём ввода после 2 с паузы (энтер по-прежнему работает), фиксация — скроллом вниз (свайп вниз, PageDown).
- Лента — цепочка одинаковых кубов: канонический кадр (исходная ориентация, текст на передней грани, без покачивания/мерцания), карточка выглядит точно как активный куб, текст — в title-подсказке.

## Чем проверено

- Поведенческие тесты на DOM-заглушках (node): ориентации текста 24/24 по проекционной трубе, негативный контроль ловил 12–20 ошибок; CPU-рендер мозаики 24 ориентаций (PIL) — визуально все читаемы.
- Сценарии poke (ожидание/отмена/ошибка/ретрай), комбинированный запрос (5 сценариев, 15 утверждений), фиксация скроллом, карточки ленты, двухсекундный автоприём (6 сценариев).
- `node --check` после каждой правки.

## Камни

- **Рабочая копия для просмотра лежала в /tmp/dovodchik** — репозиторий теперь источник истины; при следующей правке серверовать отсюда.
- Headless-Firefox без WebGL — там куб не проверить, только деградацию.
- Браузерный кэш: при проверке правок жёсткое обновление (Ctrl+Shift+R).
