# Креативный доводчик

Одностраничное приложение для пошаговой доработки текста. Вводишь черновой фрагмент — нейросеть предлагает четыре «оси смысла» и по варианту на каждую. Клик по чипу поворачивает куб с готовым текстом на грани; зафиксированные фрагменты складываются в ленту — цепочку таких же кубов.

## Возможности

- **Один файл.** Весь код — `index.html`: HTML+CSS+JS, WebGL своими шейдерами, без сборки и внешних зависимостей.
- **Любая OpenAI-совместимая модель.** Endpoint, модель, ключ и лимит токенов задаются в настройках; один объединённый запрос возвращает сразу и оси, и варианты (строгий JSON, мусорный ответ — один повтор).
- **Пресеты тональности.** Научный, литературный, фантастический, детский — кнопками в строке заголовка; без выбора действует нейтральный эксцентричный тон. Смена пресета сразу перегенерирует оси текущего фрагмента.
- **Минимум лишних нажатий.** Ввод обрабатывается сам после двух секунд паузы (энтер тоже работает); фиксация — скроллом вниз; случайная фиксация откатывается крестиком в углу сцены.
- **Приватность.** Тексты и настройки (включая ключ) хранятся только в localStorage браузера и отправляются исключительно на указанный в настройках endpoint.

## Запуск

```
python3 -m http.server 8000 --directory <путь к репозиторию>
```

Открыть `http://localhost:8000`. Работает и открытие файла напрямую — но настройки localStorage привязаны к origin.

## Как устроено

- Куб: 24 канонические ориентации (кватернионы), текст рисуется на canvas-текстурах 512×512; канонический обход UV граней, ориентация текста всегда читаема для зрителя.
- Обработка текста: debounce две секунды → объединённый запрос осей и вариантов; недостающие варианты добираются точечными запросами; поздние ответы отменённых кликов игнорируются.
- Проверяется поведенческими тестами на DOM-заглушках без браузера — описание методики и охват сценариев в [STATUS.md](STATUS.md).
