# Креативный доводчик

Одностраничное приложение для пошаговой доработки текста: пользователь вводит фрагмент, нейронка за один запрос возвращает четыре «оси смысла» и по варианту на каждую; клик по чипу поворачивает куб с готовым текстом на грани. Зафиксированные фрагменты складываются в ленту — цепочку одинаковых кубов.

## Устройство

- Весь код — единственный файл `index.html` (HTML+CSS+JS, WebGL своими шейдерами, без сборки и зависимостей).
- Куб: 24 канонические ориентации (кватернионы), текст рисуется на canvas-текстурах 512×512; зеркальный обход UV трёх граней исправлен, таблицы «верх/право» грани выводятся из GEO автоматически.
- Нейронка: OpenAI-совместимый `/chat/completions` (настраивается: endpoint, модель, ключ, лимит токенов), один объединённый запрос даёт чипы и варианты сразу.
- Хранение: `localStorage` (`dvdc_cfg` — настройки, `dvdc_texts` — архив текстов). Больше никуда не отправляется.

## Запуск

```
python3 -m http.server 8000 --directory <путь к репо>
```

Приложение также совместимо с открытием файла напрямую, но настройки localStorage привязаны к origin.

## Правила

- Инструментальный потолок: правки — только `index.html`, без сборки и внешних пакетов.
- Проверка без браузера: вырезать `<script>` в файл и `node --check`; поведенческие тесты — DOM-заглушки + заглушки fetch (см. STATUS.md).
- В headless-браузерах без WebGL приложение деградирует: окно ввода растягивается на сцену, куб не рисуется, всё остальное живо.
